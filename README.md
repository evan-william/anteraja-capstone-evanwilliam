# Anteraja Shipment Tracking Widget

Capstone ini berfokus pada pengembangan shipment tracking widget untuk membantu pelanggan Anteraja memahami status paket dengan lebih jelas. Widget akan menampilkan riwayat pergerakan paket, estimasi waktu, dan penjelasan ketika pengiriman mengalami kendala. Pengguna juga akan memperoleh tindakan lanjutan yang relevan, seperti mengonfirmasi alamat atau meminta bantuan tanpa mengulang informasi paket. Pengembangan dilakukan bertahap dengan memprioritaskan keamanan data, kesederhanaan pengalaman pengguna, dan kemudahan integrasi.
