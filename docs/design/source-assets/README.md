# Aset sumber desain

Folder ini menyimpan gambar sumber dan varian logo yang tidak dimuat UI saat ini. File tetap tersedia untuk penyuntingan desain, tetapi tidak ikut disalin Vite ke `dist/`.

- `auth/`: PNG sumber carousel; UI memakai tiga versi WebP di `public/auth/`. `sorting-hub.png` adalah visual warehouse lama, bukan slide aktif.
- `brand/`: wordmark lengkap dan varian icon; UI aktif memakai mark, mark-small, dan favicon di `public/brand/`.

Audit referensi kode dan `index.html` tidak menemukan URL keenam file ini digunakan aplikasi. Pemindahan mempertahankan aset aslinya; tidak mengganti logo atau gambar carousel yang tampil.
